PUTTING CRAFTY KORNER INDIA ONLINE

OPTION 1 (recommended): RENDER, ONE SERVICE FOR EVERYTHING
   Why not "frontend on GitHub, backend on Render"? The pages are generated by the server. When you add or edit a product
   in /admin, the server rebuilds the pages. A copy on GitHub Pages would never see those changes, and the forms/admin
   would need extra cross-site setup. One Render service serves the website AND the backend, so everything stays in step.
   GitHub just holds the code; Render redeploys from it automatically.

   1. Push the project to a PRIVATE GitHub repo (see part A below).
   2. Render dashboard > New > Blueprint > pick the repo (it reads render.yaml). 
      Or manually: New > Web Service > the repo, Language Python, Build: pip install -r requirements.txt, Start: python app.py,
      then add a Disk (mount path /var/data, 1-2 GB) and the environment variables below.
   3. Environment variables (Render > Environment):
        DATA_DIR=/var/data          (keeps products, photos, enquiries and the admin password across restarts)
        COOKIE_SECURE=1
        TRUST_PROXY=1
        SITE_URL=https://your-domain-or-onrender-url      (no slash at the end)
        SMTP_USER, SMTP_PASSWORD, NOTIFY_EMAIL           (Gmail alerts)
        WHATSAPP_TOKEN, WHATSAPP_PHONE_ID, WHATSAPP_TO   (WhatsApp alerts)
   4. When it says Live, open https://YOUR-SERVICE.onrender.com/admin/ and set the admin password IMMEDIATELY.
   5. Custom domain: Render > Settings > Custom Domains, add the DNS records it shows, then change SITE_URL to the domain.
   Notes: only ONE instance (a disk cannot be shared). The first start copies the starting products and photos onto the disk;
   after that, manage products only in /admin. Code/design updates (git push) never delete your products.

OPTION 2: A VPS (steps further below).

A. PUSH TO GITHUB (code backup; make the repository PRIVATE)
   1. Create an empty private repository on github.com (no README).
   2. In this folder (the one with app.py), open a terminal:
        git init
        git add .
        git commit -m "Crafty Korner India website"
        git branch -M main
        git remote add origin https://github.com/YOUR-USER/YOUR-REPO.git
        git push -u origin main
   The .gitignore keeps .env, the admin password file, enquiries and backups OFF GitHub.

B. GO LIVE (needs a host that runs Python and keeps its files)
   GitHub Pages / Netlify / Vercel cannot run the admin panel or the enquiry forms.
   Use a small VPS (about Rs 400-600 per month, Ubuntu) or PythonAnywhere (paid plan, so WhatsApp/Gmail can be sent).
   Render/Railway free plans lose products and enquiries on restart, so avoid them unless you add a paid disk.

   VPS steps (Ubuntu), replace yourdomain.in and YOUR-USER/YOUR-REPO:
     sudo apt update && sudo apt install -y python3-venv git nginx certbot python3-certbot-nginx
     sudo git clone https://github.com/YOUR-USER/YOUR-REPO.git /var/www/crafty
     cd /var/www/crafty && sudo python3 -m venv venv && sudo venv/bin/pip install -r requirements.txt
     sudo cp .env.example .env && sudo nano .env
        - set SITE_URL=https://yourdomain.in
        - add HOST=127.0.0.1
        - remove the # from COOKIE_SECURE=1, FORCE_HTTPS=1, TRUST_PROXY=1
        - fill the Gmail / WhatsApp lines
     sudo venv/bin/python build.py        (rebuilds pages with your domain)
   Run it as a service: create /etc/systemd/system/crafty.service
        [Unit]
        Description=Crafty Korner India
        After=network.target
        [Service]
        WorkingDirectory=/var/www/crafty
        ExecStart=/var/www/crafty/venv/bin/python app.py
        Restart=always
        [Install]
        WantedBy=multi-user.target
     then:  sudo systemctl enable --now crafty
   Nginx: create /etc/nginx/sites-available/crafty
        server {
          server_name yourdomain.in www.yourdomain.in;
          client_max_body_size 80M;
          location / { proxy_pass http://127.0.0.1:8000; proxy_set_header Host $host; proxy_set_header X-Forwarded-For $remote_addr; proxy_set_header X-Forwarded-Proto $scheme; }
        }
     then:  sudo ln -s /etc/nginx/sites-available/crafty /etc/nginx/sites-enabled/ && sudo nginx -t && sudo systemctl reload nginx
            sudo certbot --nginx -d yourdomain.in -d www.yourdomain.in
   Point your domain DNS (A record) to the VPS IP. Then open https://yourdomain.in/admin/ and set the admin password IMMEDIATELY.

C. AFTER GOING LIVE
   - Manage products only in /admin on the live site (it changes files on the server).
   - For code updates: git stash && git pull && git stash pop, then sudo systemctl restart crafty.
   - Download the Excel from the admin now and then as an extra backup.
